# GP Vegetable & Fruit – GitHub Menu
1. Create a GitHub repository (for example `gp-vegetable-menu`).
2. Upload `index.html` and `menu.html` to the repository root.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Open the published `index.html`.
5. Enter shop name/address/logo, select items, enter prices/offers.
6. `PDF of Selected` prints only selected items.
7. `Create Customer QR` creates a QR containing the selected item list and prices.
8. The QR opens `menu.html` and loads product photos online.
Important: customer QR requires the GitHub Pages site to be online. Photos require internet.
