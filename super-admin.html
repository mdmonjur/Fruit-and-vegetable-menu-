MR MONJUR · Super Admin

Retailer Admin account তৈরি ও login details পাঠানোর প্যানেল

১. Supabase সংযোগ

আপনার Supabase Project URL এবং Publishable/anon key দিন। এগুলো এই ব্রাউজারে থাকবে। Service Role Key এখানে দেবেন না।

২. Super Admin Login

যে account-এ mm_profiles-এ platform_role = super_admin সেট করা আছে, সেটি ব্যবহার করুন।

৩. নতুন Retailer ও Admin তৈরি করুন

Retailer-এর নাম, Admin login email/username এবং প্রাথমিক password তৈরি করুন। password অন্তত ৮ অক্ষরের হবে।

গুরুত্বপূর্ণ: account তৈরি হওয়ার পর retailer এই নতুন login দিয়ে sign in করবে। পুরোনো shared-data HTML-এ এখনো আলাদা tenant data wiring সম্পূর্ণ না হলে এই login একা পুরোনো stock/sales-কে আলাদা করবে না। Production ব্যবহারের আগে tenant-enabled app integration ও data migration দরকার।

কীভাবে চালু করবেন

  1. প্রথমে supabase/schema.sql Supabase SQL Editor-এ চালান (প্রথমে backup/staging ব্যবহার করুন)।
  2. Supabase Dashboard → Edge Functions-এ create-retailer-admin deploy করুন।
  3. Function secrets-এ SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY সেট করুন। Service Role Key কখনো HTML-এ রাখবেন না।
  4. প্রথম Super Admin-কে trusted SQL/admin process দিয়ে mm_profiles.platform_role='super_admin' দিতে হবে।
  5. তারপর এই পেজে URL/key দিয়ে Super Admin login করুন।

এই পেজ account provisioning-এর জন্য। পুরোনো management file সংরক্ষিত আছে legacy-management-preserved.html নামে; তার বিদ্যমান সব ফিচার tenant-aware cloud database-এ যুক্ত করতে আলাদা integration প্রয়োজন।
